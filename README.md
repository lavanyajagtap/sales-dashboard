# 📊 Superstore Sales Report Dashboard

## 1️⃣ Project Title / Headline

### Superstore Sales Report Dashboard using Power BI

An interactive Power BI dashboard designed to analyze sales performance, profit trends, regional performance, and category-wise business insights using the Superstore dataset.

---

## 2️⃣ Short Description / Purpose

This project focuses on analyzing retail store sales data to identify key business insights and improve decision-making. The dashboard provides a clear understanding of sales, profit, quantity, discounts, and regional performance through interactive visualizations.

The main purpose of this project is to:

* Monitor overall sales performance
* Compare profit across regions
* Analyze category-wise sales
* Track business KPIs
* Support data-driven decisions

## 4️⃣ Data Source

### Dataset Used:

Superstore Sales Dataset

The dataset contains retail business transaction data including:

* Sales
* Profit
* Quantity
* Discount
* Category
* Region
* Customer information

This dataset is widely used for data analytics and visualization projects.

## 5️⃣ Features / Highlights

### Dashboard Features

✔️ KPI Cards for:

* Total Sales
* Profit
* Quantity
* Discount

✔️ Region-wise Sales Analysis

✔️ Category-wise Sales Distribution

✔️ Sales vs Target Comparison

✔️ Interactive Map Visualization

✔️ Profit Analysis by Region

✔️ Business Performance Insights

---

## 📈 Key Insights

* West region generated the highest sales.
* Technology category contributed maximum revenue.
* Sales and profit performance can be compared region-wise.
* Interactive visuals improve business understanding and reporting.
